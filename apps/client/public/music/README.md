# Map music (local only)

Third-party tracks are **not** committed (`*.mp3`/`*.ogg` are gitignored here). Drop your own files in this folder;
a missing file just means that map plays no music.

| File               | Plays on                         |
| ------------------ | -------------------------------- |
| `warzone.mp3`      | Warzone maps (Rustwater Canyons) |
| `city-concord.mp3` | Concord city (Gildspire)         |
| `city-vex.mp3`     | Vex city (Rivet Harbor)          |

The Lobby/hangar is silent. Tracks loop; they fade between maps and on leaving to the Lobby.
