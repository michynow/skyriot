# SKYRIOT

Nation-vs-nation arcade flight combat in the browser. React-three-fiber client, Colyseus + Rapier authoritative server.

```bash
pnpm install
pnpm dev          # server ws://localhost:2567, client http://localhost:5173
pnpm db:up        # Postgres (M2+)
```
